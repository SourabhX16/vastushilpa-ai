# Vastushilpa AI

Vastushilpa AI is a preliminary residential planning tool that turns plot and room requirements into a Vastu-informed floor plan, energy screening estimates, structural checks, and drawing exports for review.

Its three-way idea combines **Vastu** spatial guidance, **energy** considerations such as daylight and ventilation, and **IS 456** structural checks in one workflow. These lenses inform the same plan; they do not replace design review by qualified professionals.

```text
Plot + brief
    │
    ▼
Ayadi + Vastu grid
    │
    ▼
Three layouts (Vastu-first · energy-first · balanced)
    │
    ▼
Structural check + energy estimate
    │
    ▼
Plan / 3D / DXF / A3 sheets
```

## Run locally

```sh
npm install
npm run dev
npm test
```

Live demo: [vastushilpa-ai.vercel.app](https://vastushilpa-ai.vercel.app)

**Sample project:** 30 × 40 ft, east-facing, Bhopal, 3BHK.

## Status and limitations

- Ayadi formulas and Vastu rules are encoded from secondary sources. Their data entries are marked `verified: false` pending primary-source verification.
- Energy figures are simplified screening estimates, not a building energy simulation.
- IS 456 checks are simplified preliminary checks. A licensed structural engineer must review and approve any design before construction.
- Layouts come from a deterministic, rule-based generator with a constrained search; they are not generated by a generative model.
- A 3BHK on a 30 × 40 ft plot is represented as a G+1 plan, with some bedrooms on a notional first floor. Parking may not fit on the ground floor.
- DXF export opens in AutoCAD. IFC and Revit export are on the roadmap.
